Configuración central

Los tres visores trabajan desde esta publicación central. Para futuras actualizaciones solo reemplaza la carpeta docs del repositorio central-que-comer; no necesitas volver a editar los otros repositorios.
Este enlace se genera desde la misma carpeta central y transmite automáticamente la conexión de Firebase.
El mismo enlace sirve para todos los negocios; cada dispositivo queda vinculado al establecimiento que activas desde Control.
Por defecto 1%. Se acredita cuando el negocio finaliza el pedido. El cliente puede usar el saldo acumulado en compras posteriores.
